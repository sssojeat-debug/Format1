# Format1 VideoExpress Clip Prompt

Create **ONE vertical 9:16 clip, maximum 10 seconds**, using VideoExpress's actual supported duration. Duplicate this template for every scene. Maintain identical immutable character and voice descriptions across prompts. Never substitute realistic humans for requested 3D animated characters.

**Part / scene:** [part ID / clip number / name]  
**Duration:** [actual app selection: >0s and ≤10s]  
**Output:** vertical 9:16, target 1080 × 1920  
**Visual style:** [same precise project style throughout]  
**Location:** [exact space/layout and time/lighting]  
**Reference assets:** [supplied character images and, if supported, prior clip's actual last-frame image]

**Characters / fixed voice anchors**
- [Name 1]: [paste exact unchanging face, hair, proportions, clothes, shoes and voice reference/ID + accent, tone and pacing]
- [Name 2]: [same]
- **Only the listed characters appear.** Preserve each voice identity and assign each line only to its intended speaker.

**START / first frame:** Immediately continue clip [previous ID] at its ending instant: [camera shot/framing, location, exact pose, screen placement, eye direction, which hand holds which prop, light and background]. Use the actual last rendered frame of clip [previous ID] as the start-image/reference when supported. No teleporting or time jump.

**ONE MAIN ACTION:** [single physically plausible movement with direction and timing]. Keep faces and outfits unchanged, body anatomy natural, and props stable. [Specific camera behavior, ideally one continuous shot.] Preserve real-world scene geometry and avoid surprise cuts.

**DIALOGUE / speech audio:**  
[NAME] ([same voice ID, timbre, accent and pace in all clips]): "[Exact concise English sentence.]" [Accurate speaking lip-sync.]  
[NAME, if needed]: "[Exact second short sentence.]" [Only this person speaks their line; listener stays silent.]

**Narration:** [None unless requested.]  
**SFX / music:** [scene-specific sounds and continuous music/ambience; keep speech audible].

**END / last frame:** [precise final camera composition, subject positions, gesture, gaze, hand/prop placement, ongoing movement and light]. This exact instant is the next scene's starting state. Save/reuse the rendered final frame when app supports that workflow.

**STRICT NEGATIVE TEXT RULE — NO SUBTITLES:** Do not generate subtitles, captions, onscreen dialogue text, title cards, lower thirds, logos, watermarks, visible UI, signs, labels, lettering, gibberish glyphs or any other readable text anywhere in ANY frame.

**Other negatives:** No changed faces/hair/clothing/shoes or voice, extra humans, duplicate characters, extra fingers/hands/arms/limbs, morphed objects, switching prop ownership, impossible door directions, sudden location changes, reversed walking direction, unrequested narrator, overlapping wrong speaker, jump cuts or new camera angles.

**Acceptance check (after rendering):** actual clip ≤10 seconds, 9:16; no text; same characters and voices; correct speaker lip-sync; correct physical continuity; ending frame matches subsequent start. Retake material failures if authorized; do not claim verification without viewing the result.
